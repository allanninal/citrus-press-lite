== Description ==

A fresh, clean block theme for juice bars, smoothie shops and wellness cafés. Patterns for a hero, menu highlights, the full menu with ingredients and calories, juice cleanse programmes, the farms you source from, your story, a photo gallery and opening hours, all editable in the Site Editor.

Citrus Press Lite is a block theme: every page, header and footer is edited in the Site Editor, with no page builder. The front page is built from patterns you can rearrange, and each section is also in the pattern inserter for any page.

A contact form is plugin territory: for a form on your contact page, install a form plugin from WordPress.org.

The full version of Citrus Press adds a one-click demo import (pages, menu, photos and journal posts), a WooCommerce shop set up with products and photos, a dark style and a setup guide: https://checkout.freemius.com/theme/43064/plan/74969/

== Frequently Asked Questions ==

= Does the theme collect any data? =

No. Citrus Press Lite sets no cookies and uses no tracking. To offer updates it asks GitHub (api.github.com) for the latest release of github.com/allanninal/citrus-press-lite, at most twice a day; that request carries nothing about your site. The upgrade notice in the dashboard is a plain link; dismissing it is stored on your own site.

= How do I update it? =

Like any theme: new versions appear under Dashboard › Updates. Each version is also a release at https://github.com/allanninal/citrus-press-lite/releases, with the theme zip attached. Install that zip, not GitHub's "Source code" download, whose folder name is different.
